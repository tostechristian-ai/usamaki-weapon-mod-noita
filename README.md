# Usamaki Weapon Mod for Noita

A powerful sword wand mod for Noita, inspired by Terraria's Night's Edge.

## Features

- **Usamaki Wand**: A powerful melee wand that spawns at the start of each run
- **Random Spawns**: Also spawns randomly in dungeons, shops, and wand pedestals
- **Custom Graphics**: Includes custom sprite graphics for the weapon

## Installation

1. Download the mod:
   - From [Releases](https://github.com/tostechristian-ai/usamaki-weapon-mod-noita/releases) (recommended)
   - Or direct download: [main.zip](https://github.com/tostechristian-ai/usamaki-weapon-mod-noita/archive/refs/heads/main.zip)

2. Extract the zip file (this will create a folder called `usamaki-weapon-mod-noita-main`)

3. Move the extracted folder to your Noita `mods` directory:
   - Windows: `C:\Program Files (x86)\Steam\steamapps\common\Noita\mods\`
   - Linux: `~/.steam/steam/steamapps/common/Noita/mods/`

4. Final path should look like:
   - `C:\Program Files (x86)\Steam\steamapps\common\Noita\mods\usamaki-weapon-mod-noita-main\`

5. Launch Noita and enable the mod in the mod menu

## Usage

- The Usamaki wand spawns automatically to the left of your character at the start of each run
- It can also be found in shops, dungeons, and wand pedestals throughout the game
- Use it like any other wand in Noita
